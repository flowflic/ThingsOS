升级设备固件

先检查应用包，再确认写入备用应用槽。新固件通过启动健康检查后才完成升级。

1. 选择并检查应用包

Read Pico / ESP32-S3 · ThingsOS_native 应用 .bin，最大 10.875 MiB。完整 USB 镜像不能用于 OTA。

尚未检查

2. 确认升级

已检查文件头、芯片、项目、容量及 SHA-256。设备写入时再次校验，并在验证完整镜像后选择启动槽。

恢复策略

写入失败时保留当前启动槽。新版启动失败时回退；旧槽不可用时进入独立救援。用户书籍保留在 SD 卡。

通过 USB 安装 ThingsOS

完整安装或恢复

  1. 备份内部设置，保留 SD 卡书籍。
  2. 用 USB 数据线连接 Read Pico，打开本地 ThingsOS USB 安装包中的安装页面。
  3. 核对版本、清单与 SHA-256，选择串口后确认完整安装。

设备无法启动时，在设备“设置 → 恢复”进入 ROM 下载模式，或使用官方硬件下载操作。

完整安装替换设备分区与内部设置；日常升级请使用 OTA 应用包。
