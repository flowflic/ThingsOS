## 实现

- 参考 E-INK4 Plus 的有界图片思路，保留 JPEG MCU 分块缩小和 PNG 双行流式解码。
  新增 Pico 所需的 WebP 灰度分行输出，直接在行回调中缩小、对白底合成透明度，避免保留整幅 Y/U/V/A 输出后再复制灰度图。
- WebP ALPH 中间历史采用完整像素值的字典索引存储；字典不足时按原值晋升为 32 位历史，仍受原来的 3 MiB 库内预算限制。
  非裁剪、无全图去量化的 ALPH 使用 64 行窗口；其他情况保留完整 alpha 平面。保留原来的滤波、反变换和色彩缓存语义。
- WebP 因内存不足失败时，有界重试较小输出；损坏流不以缩小为由无限重试。
- 渐进式 JPEG 在灰度阅读时保留亮度系数，将不用的色度系数缩为非零位图，亮度系数按 32 KiB 小块分配。
  最后一次 IDCT 直接写入有界阅读图片，避免完整源尺寸像素平面；普通解码接口也提前释放已不再使用的系数。
  RGB/CMYK 等仍需完整色彩分量的情况保留通用路径。
- manifest 只长期保留资源路径和分类标志；ID 在打开阶段使用后释放，已存在路径复用 ZIP 名称。
  没有片段定位的书不分配每章 160 字节的空片段表；需要片段的导航正常分配，原书源章节/位置语义保留。
- 开 EPUB 时让出可重建的书库缩略图；图片加载遇到低内存时让出预绘页、缩略图和字体位图缓存。
  字体本体、字宽度量、字号、阅读位置保留，后续文字可重新填充位图缓存。

`patch_webp_alpha.py`、`patch_stb_grayscale.py` 从固定的上游源码生成构建副本；
固定 vendor 文件与其哈希保持不变，生成文件保留原许可证。`verify_build.py` 校验生成副本可重现和编译输入边界。

PSRAM 测试的总预算采用本次设备开书前的剩余量，统计解析器、ZIP、图片输入和解码缓冲的同时存活分配；
它是主机分配模型，不能代替当前设备碎片分布、联网时最低堆、任务栈余量或屏幕图像质量验收。
非交错、8 位及以下 PNG 使用原有行解码；大幅交错/16 位 PNG、特殊 JPEG/WebP 仍受通用路径、格式和内存限制。
