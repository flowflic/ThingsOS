## 功能范围

- 本地 EPUB：ZIP、manifest、逻辑章节分别支持最多 10240 项；OPF/导航 XML 最大 2 MiB，单章 XHTML 仍限 512 KiB，普通解压成员限 2 MiB。没有新增整本 EPUB 文件大小限制；并非任意体积书籍均能打开，实际还受内存和格式约束。
- 大书按实际资源/章节数量分配内存；ZIP 重复检测、资源索引查询和导航构建采用新实现；目录标题和微读子目录分步补全；分页支持中断检查点。
- 图片：JPEG 分块采样及白块饱和修正、PNG 双行流式解码、WebP（不含动画）解码；插图按正文区域等比例放大/缩小，整图不足以放进剩余正文时移到下一页；查看器适应宽度并可拖动长图。
- 微读：按章在线阅读、当前章及后两章预备、后续两章预取到 SD、已加载章节离线读取、取消/失败重试、章节/划线/云端位置跳转；保留整本离线缓存。
- 搜索：书架结果与最多 20 条线上书籍结果合并，非书架书籍可在线阅读或主动加入书架；搜索完成、失败和空结果分别处理。
- 同步带入图片重定向缓存、旧在线图片缓存补全、取消清理和阅读进度队列相关修复。

保留 Pico 官方 BSP、面板时序、电压、波形、锁屏/唤醒路径及既有字体刷新策略。未移植 Metalio 的音频、蓝牙、IMA、前光和按键硬件功能。

## Pico 内存约束

- 章节标题/片段、书脊、源章节和层级全部改为按实际章节数分配，约 **329 字节/章**，增长失败时原表保持有效。此前 2048 固定槽位仅这些数组就占 658 KiB。进度权重另按实际章节数分配，在线阅读不建立整书分页表。
- 不引入 Metalio 的额外两张解码图片缓存（最多 2 MiB）。继续使用 Pico 可回收的文字页预绘，图片解码和低内存在线请求会让出这些可重建缓存。
- 微读只有一个协调任务和单路 TLS，不创建 Metalio 的两条额外预取任务/TLS 连接。章节窗口写入 SD，不同时驻留三章解码正文。在线阅读/搜索/整本下载启动前检查现有内存门限。
- 大于 4096 字节的通用 PSRAM 申请/扩容失败后不回落内部 SRAM；小对象保留原有回退。图片输出始终使用 PSRAM。无 PSRAM 救援工程保留原来的内部堆回退，以免影响恢复控制请求。
- WebP 的库内同时存活分配最多 3 MiB，申请和灰度输出都检查保留 512 KiB PSRAM；这些是上限和拒绝条件，不是预先占用或预留的池。分配失败正常返回。
- 主 UI 栈仍为 24 KiB，微读协调任务栈仍为 16 KiB，TLS 保持外部内存分配。保留堆破坏检查、主 UI 单函数栈帧 4096 字节编译门限和现有运行时内存/栈余量日志。

旧日志 `build/weread-underrun-fixed-live-20261025.log` 曾记录 Pico 微读运行时 PSRAM 剩余 1860680 字节、内部 DMA 剩余约 55 KiB。它是历史样本，不能证明当前设备余量。图片回归用这一 PSRAM 数量及 1736692 字节碎片块模拟约束；另测 PSRAM 失败时不挤占大块内部 SRAM、WebP 总预算和章节数组增长回退。
