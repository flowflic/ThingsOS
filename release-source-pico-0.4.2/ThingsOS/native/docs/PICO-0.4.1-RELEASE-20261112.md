# Read Pico 0.4.1 发布记录

2026-11-12 按用户授权将 Read Pico 发布为 0.4.1，并更新官网：
https://thingsos.scholarcn.com/ 与 https://thingsos.vercel.app/。

本次发布包含本地 EPUB 大书内存优化、JPEG/PNG/WebP 有界解码、插图与长图阅读，
以及此前尚未公开发布的微读按章在线阅读、图片缓存、阅读位置恢复和充电状态显示。
详细更新项以 `native/release-notes.json` 为准。

## 构建与线上验证

- 主应用及救援固件均以 0.4.1 重新构建；USB 标识同步为 0x0401。
- 功能代码沿用已通过 43 项主机测试、两本原书共 109 张图片测试的修复候选。
  发布构建重新执行集成检查，复用该轮功能测试记录；本次未重复运行整套主机测试。
- 站点安装测试通过，包括真实 USB/OTA 分区、浏览器启动及损坏包/错误项目/偏移/清单拒绝检查。
- 部署前核对实际生产基线，保留 Metalio 0.1.7 的固件、页面资源和发布历史。
- 部署后分别从两个生产域名下载并核验清单、页面资源、USB/OTA 固件与各分区 SHA-256；
  Metalio 保留资源逐项下载比较通过，旧版下载路径按现有站点策略返回 404。

## 设备状态

本次官网发布没有再次烧录设备。设备仍为先前安装并通过启动健康检查的 0.4.0 修复候选，
见 `native/docs/PICO-LOCAL-EPUB-IMAGES-20261112.md`。
0.4.1 的确切镜像尚未实机安装；原书图片显示与清晰度、在线阅读和运行时最低内存仍待设备验收。
没有提交 Git 变更。
