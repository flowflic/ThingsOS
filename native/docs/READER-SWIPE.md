# 阅读页上下滑动翻页

2026-11-12：阅读正文区域支持上滑下一页、下滑上一页，默认可用，没有新增设置项。

- 在松手时识别，一次手势只翻一页。
- 纵向位移超过 40 个屏幕逻辑像素，且大于横向位移才识别。短距离抖动、横向滑动和移回原点不作为正文点击。
- 保留状态栏下拉控制中心；图片放大查看中的拖动、文字选择、进度拖动、菜单、脚注、笔记及其他弹层优先处理，不触发翻页。
- 使用旋转后的阅读坐标，横屏、沉浸模式和竖排正文保持相同的“上滑下一页／下滑上一页”方向。
- 接入共享 `next_page()`，本地与微读阅读共用现有分页、跨章、缓存、位置保存和刷新策略；第一页／最后一页沿用既有提示。

实现：`firmware/main/main.c` 的 `reader_swipe_page()` 及主触摸循环的松手分支。未修改图片拖动、列表滚动或面板驱动。

回归：`tests/reader_swipe_ui_test.inc` 通过真实控制器执行翻页，覆盖正常／沉浸／横屏 × 横排／竖排、阈值、方向、长滑只翻一页、首页边界，以及菜单／图片／文字选择／密码锁定等手势所有者互斥。最终测试和开发镜像存于 `build/reader-swipe-20261112/`。

版本保持 0.1.7。主机与构建验证不代表实际设备触摸体验和面板验收；本次未烧录、未发布。
