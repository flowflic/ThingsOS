# 离线阅读时长单开关交互

2026-11-13，Metalio 开发候选，版本保持 0.1.7。

以下为独立离线开关的历史实现记录。2026-11-14 后已合并到同步页的阅读时长总开关，当前行为见 [统一开关与当日统计](WEREAD-DURATION-UNIFIED.md)。

默认页面仅显示“离线阅读时长补传”一个操作开关，保留待上传、待确认和运行状态等只读文字。移除常驻授权和立即上传按钮。

2026-11-14 默认值调整：未保存过 `wd-offline` 设置或设置值无效时，离线阅读时长补传默认开启；已保存的开启/关闭设置继续生效，用户手动关闭后重启仍保持关闭。加载默认值不会自动弹出授权或启动网络任务，已有阅读时长同意和账号授权条件继续生效。

- 开启时复用已保存的同账号 Native 授权，可在离线状态下启用已有有效授权。首次授权与 Web 登录仍独立，缺少授权、已失效或认证错误时自动打开二维码；只有本次授权成功、同账号校验通过且设置落盘成功，才把原本关闭的开关改为开启。
- 取消、授权失败、启动失败和设置保存失败均保持原设置。显式取消立即撤销待启用意图，避免取消操作与成功回执交错时误开启。遇到封面等后台任务时先取消后台，再启动前台授权；中间的取消回执不作为授权结果。
- 已开启但授权失效时才显示“重新扫码授权”。该入口不切换原开关；失败后仍保留设置和待发时长。
- 云端位置冲突时才显示核对入口。用户明确核对后解除位置阻止，交给联网空闲自动补传，保持已有持久化冷却。
- 有发送结果未知的记录时显示说明入口。返回键先回到开关页；该说明没有重发或删除动作，`.sent` 记录始终保留，避免重复计时。
- 关闭后立即暂停采集和自动补传，保留待发、待确认记录。计时通道变更仍在再次开书时应用，原有阅读时长同意开关保持生效。

授权完成回调在 `weidu_poll` 处理真实请求结束时运行，独立于用户是否仍停留在该页面；其他请求替换原请求时撤销待启用意图。Native 账号一致性校验、账本、POST 认领及不确定结果保护未改动。

验证证据写入 `build/readtime-toggle-20261113/`。主机控制器回归覆盖授权完成、失败、取消、持久化失败、离线复用、后台任务让位、条件入口和队列保留；真实扫码、账号入账与设备显示仍需实机验收。实现阶段未烧录，后续已按用户明确要求完成 USB 安装、完整回读和启动健康检查，见 [安装记录](DEVICE-INSTALL-20261113-READTIME-SINGLE-TOGGLE.md)。未发布或更改版本号。

本次主机 UI 控制器、真实传输函数故障注入回归均通过，ESP32-S31 主固件编译、应用 JPEG 符号检查通过。渲染截图已检查正常单开关页与待确认说明页。最终固件、ELF、源文件哈希与验证范围见该目录的 `validation.json`；候选包含此前尚未烧录的当前目录定位/浅灰背景和授权二维码响应容量修复。
