# 快速模式字缘优化（2026-10-26）

前置条件：用户已确认 DU 白底维护候选的阅读行间细线消失；对应记录见 [READER-FAST-LINES.md](READER-FAST-LINES.md)。本轮仅调整字体二值化，不改变该候选的 20 相 DU、白向维护、全刷间隔或更新后立即断电。

## 调整

原实现把 FreeType 灰阶覆盖率送入固定 4×4 Bayer 网格，并用屏幕坐标选择阈值。边缘出现周期性毛点，同一字在不同位置可能有不同的断点；最低阈值为零，还会保留极弱的覆盖像素。

新实现以字形为单位作蛇形误差扩散，将覆盖率误差分配给相邻像素；强覆盖与近透明像素固定为黑与白，防止误差在实心笔画上挖孔或在轮廓外生成杂点。最终仍是单色 DU 空间覆盖，无法等同于真实灰阶面板驱动。

- FreeType 的轮廓、hinting、字号、字重、斜体、advance 与分页保持原值。
- 灰阶字形缓存保持原格式，热缓存/直绘共用一条混合路径。图案跟随字形，移动和裁切不改变可见字缘。
- 不为每个字新增分配；误差暂存为两个 258 项 int16 行，共 1032 字节栈空间。超宽自定义字形安全退回阈值二值化。
- 灰阶阅读、原生 mono 字形与背景混合继续沿用原输出语义。
