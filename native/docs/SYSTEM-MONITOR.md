仅在系统页可见且设备醒着时每 2 秒采集一次。触摸、页面切换、控制中心和待呈现帧优先；后台统计更新不记录用户活动，不推迟自动锁屏。离开页面或休眠后停止采样，返回重新建立 CPU 采样基线。

首次进入使用常规页面呈现。初版定时更新使用整块 GL16 区域呈现，用户实机反馈每次更新闪烁严重，因此改为 `thingsos_board_present_metrics()`：复用阅读后台维护的灰阶差分路径，比较前后帧，仅扫描变化行，使用已有的等值像素保持 GC16 表，未变化的背景、图表和文字不再反复驱动；完全相同的帧不扫描。保留浅灰图表底色，且不受阅读快速模式的二值化影响。首次呈现、显式清理和错误恢复仍优先走原有完整刷新。扫描结束立即断电并校验空闲。没有改写波形、电压、硬件驱动时序或充电策略。修复后的实机观感仍需验收。

## 数据口径

- CPU 频率：`esp_clk_cpu_freq()` 的当前 MHz，比例上限为构建配置的 CPU 默认频率；只读，不调频。
- CPU 使用率：两核各自的忙碌时间比例再取平均，100% 表示两核完全忙碌。使用 FreeRTOS 64 位 ESP timer 运行时计数与各核 idle 计数的差值；首次或间隔超过 10 秒显示“采样中”。不足 500 ms 的手动刷新保留上次有效窗口。读取另一核使用短 IPC 回调，使仍在 idle 的核心先发生任务切换、提交其 idle 计数，避免直接跨核读取陈旧计数。IPC 失败显示采样异常。
- SRAM：`MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT` 的可分配堆总量和空闲量。不是芯片规格表中的物理 SRAM 总量。
- PSRAM：`MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT` 的可分配堆总量和空闲量。
- 最大连续空闲：通过 `heap_caps_get_info()` 获取上述两类堆的 `largest_free_block`，分别按 KiB / MiB 显示，是单次可申请连续空间的观测值，不保证未来分配成功。空闲及最大块来自同一次堆信息汇总，总量沿用 `heap_caps_get_total_size()` 的原有口径。
- Flash：芯片容量为总量；剩余空间指当前运行应用分区内镜像尾部的升级余量。占用量包括当前镜像和所有其他预留分区，二者之和等于芯片容量。通过运行分区和镜像元数据获取镜像长度，不遍历或改写 Flash，不包含 SD 卡书籍空间。无法读取时显示不可用。
- 屏幕扫描时钟：只读 `metalio_epd_pclk_mhz()` 当前 PCLK 配置，能显示已有 20 / 10 MHz 回退状态；不是刷新次数或对引脚频率的仪器测量，屏幕空闲时仍显示扫描使用的配置。不增加调频操作。
- 最近刷新耗时：最近一次成功完成的显示呈现调用耗时（ms），包含上电、温度读取、打包、扫描及返回前的即时收尾，不含上层页面布局或后台保留供电的空闲时间。采样时读取上一帧已完成的数据，系统页自己的刷新也计入；未发生扫描的相同帧、失败帧不覆盖最近成功记录。尚无成功记录时显示 `--`，小于 1 ms 的成功记录可显示 `0 ms`。

内存数字按 KiB/MiB 显示，进度比例使用原始字节。没有 SD 卡或网络也能使用。统计器由 UI 主任务调用，没有创建常驻采样任务。FreeRTOS 运行时计数全局启用，会带来任务切换计时开销；该开销及实际 CPU 使用率需在设备上观察，主机测试不能证明实机负载准确性。

2026-11-17：新增“DMA 内存”页签，显示 `MALLOC_CAP_INTERNAL | MALLOC_CAP_DMA | MALLOC_CAP_8BIT` 的总量、已用、可用及最大连续块，统计口径与当前 I2S 驱动的缓冲分配要求一致。它是内部 SRAM 的重叠子集，不与 SRAM 相加；不包含 PSRAM。沿用两秒采样和低闪差分呈现。音频分配失败证据、候选修复及验收边界见 [音频 DMA 记录](AUDIO-DMA-START-20261117.md)。

## 实现与验证

- 核心计算：`native/src/system_monitor.c`，独立的双核窗口、Flash 容量和有界比例计算。`thingsos_board/display_stats.inc` 由 UI 主任务记录成功帧耗时，并只读当前 PCLK。
- 设备适配：`native/firmware/components/thingsos_system/`，只读 ESP-IDF 数据接口。
- 页面与生命周期：`native/firmware/main/system_ui.inc`、主任务呈现和应用入口。
- 主机用例：`system_monitor_test.c` 覆盖双核归一化、首次窗口、快速刷新、间断/回退、跨 32 位时间边界、Flash 边界、比例溢出；`system_monitor_ui_test.inc` 覆盖入口、未知/有效/不可用状态、区域呈现、触摸优先、返回、休眠和后台刷新不修改活动时间。
- 初版构建与渲染记录于 `build/system-monitor-20261114/`；闪烁修复记录于 `build/system-monitor-low-flash-20261114/`；新增三项指标记录于 `build/system-extra-metrics-20261114/`。截图是实际 C 页面渲染器在模拟数据下的结果，不是设备截图。

实机待验收：首次 CPU 采样、空闲/忙碌双核使用率、连续运行、自动锁屏、退出后停止采样、灰阶图表区域刷新，以及与真实分区/堆统计核对。需要用户另行授权烧录。
