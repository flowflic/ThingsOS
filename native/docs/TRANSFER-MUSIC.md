# 传输：书籍与音乐（2026-10-27，保持 0.3.6）

用户已确认 `build/prototypes/metalio-apps-controls/transfer-music.html` 原型。
设备端入口、标题和手机页面统一使用“传输”。设备选择书籍/音乐后，二维码
携带 `kind=books/music`，手机默认选择对应类别，也可自行切换。

音乐仅支持 MP3、WAV，目录固定为 `/sdcard/music`。手机端隐藏音乐目录跳转，
服务端独立检查目标路径，不能通过请求参数改写到其他目录。目录不存在时创建。
音乐使用原始文件字节，不进入图片转换。书籍继续使用原有自定义书库路径。
同名沿用已有保留两份、替换、取消流程；传输进行中不能切换设备端类别。

`web_transfer_test.cjs` 执行实际手机控制脚本与图片预处理模块，覆盖分类入口、
固定目录、MP3/WAV 原始字节、错误扩展名、同名重试、取消和书库目录保持。
设备 UI 测试覆盖分类、进度和阻止忙时切换。32 项主机回归全部通过。

设备原生渲染位于 `build/bluetooth-20261026/ui-transfer-books.png` 与
`ui-transfer-music.png`，已核对文字、按钮和底部“应用”选中状态，无布局溢出。
尚未安装当前整合固件；真实手机经 Wi-Fi 上传、SD 卡落盘及音乐应用播放仍待
目标设备验收。原型演示上传不等于设备上传证据。
