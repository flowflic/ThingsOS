# 微读居中加载卡片与预取批处理（2026-11-04）

用户已确认 `build/prototypes/weread-loading-20261103/` 的卡片布局和约 0.8 秒一步的转圈节奏。
本轮按该 UE 实现，保持 Metalio 0.1.5，不发布、不新增提交。

## 行为

- 初始缓冲：532×430 居中白卡片、12 段指示圈、实际就绪章数、完成后自动进入阅读。
  目标为当前位置及后两章，书尾按剩余章数收窄，不用模拟百分比或预估时间。
- 跨章加载：保留原正文位置；就绪后自动进入目标章。沉浸模式不改变正文排版。
- 失败：显示错误卡片，保留已经完成的章节和定位请求，支持重新加载与取消。
  离线重试保留错误卡片并提示连接 WiFi，取消不删已缓存内容。
- 卡片打开时拦截背景点击、翻页、书架滚动和长按操作；返回/菜单取消，Home 先取消再导航。
  闹钟、锁屏和控制中心保持自身优先级。

## 显示实现

`weidu_loading_card.inc` 在主任务绘制。第一帧合成背景和卡片，后续转圈直接更新
64×66 逻辑像素；进度/失败状态变化更新 552×450 卡片区域。动画不重排正文，
不更新用户活动时间，不消耗普通翻页的全刷计数。状态栏按原有周期独立更新。

新增 `thingsos_board_present_loading()` 只打包指定区域并使用既有 GL16 区域刷新，
保留灰度段；未更改 LUT、时序、PCLK 或 VCOM。显式全刷、首帧和错误恢复仍优先。
每次区域刷新完成后立即断轨并执行既有输出状态校验，不保留 UI 三秒供电窗口。
横屏把逻辑卡片和区域换算到既有倒置竖屏驱动坐标，不修改硬件旋转设置。

## 缓存优化

包含上一轮已验证但未安装的三章同批处理、两个既有上下文预取任务，以及协调任务
串行正文下载/规范化/逐章原子发布。只为缺失章预取，上下文任务创建失败则串行回退。
浏览微读书架/搜索时延后自动进度队列，数据仍持久保留，不与新的前台打开抢占任务。
提前取得阅读页必需字段时可结束下载，未读完的连接丢弃；完整响应允许继续复用。
