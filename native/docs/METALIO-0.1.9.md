# Metalio 0.1.9 发布

2026-11-15 用户要求升级到 0.1.9、Git commit 并上传官网。本版包含自正式版
0.1.8 后累积的微读分部目录、音频内存与局部显示、壁纸管理和本次诊断日志功能。
准确的官网更新说明保存在 `native/release-notes.json`，Read Pico 的发布文件与历史独立保留。

## 日志与升级方式

设置 → 日志可打开本地传输网页下载诊断包，独立急救网页也支持下载。
完整诊断字段在 SD 卡固定容量轮转，无卡/挂载失败才在 Flash 保存核心摘要；
SD 初始化中先等待，日志不包含账号凭据、书名或正文。
详细字段、容量和取证边界见 `DIAGNOSTICS-20261115.md`。

**OTA 仅更新主程序。要让旧急救环境也支持日志导出，需要安装完整 USB 包。**
完整 USB 包会重置内部设置，SD 卡文件保留；不应为了保留设置而手工覆盖正在运行的分区。
开发者保留设置的 USB 操作仍须遵守 `METALIO-USB-FLASH-PROCEDURE.md`。

## 验证边界

此前 0.1.8 诊断候选已安装到同一 Metalio：新急救/主程序的完整备份、实际启动、
整片回读、保护区域/NVS、启动选择器及 45 秒健康检查均通过。
本次 0.1.9 版本描述符和 ELF 发生变化，分别构建、打包和发布，不在本轮操作设备串口。
主机/安装包校验不等于日志实际导出、弱网、长期待机或面板光学验收；
音频文字残笔未声称已解决，也不把启动日志当作原用户异常根因的证明。

发布证据目录：`build/publish-metalio-0.1.9/`，包含发布前官网基线、构建、
主机回归、安装包/源码校验、发布结果及两个域名的线上哈希核验。
