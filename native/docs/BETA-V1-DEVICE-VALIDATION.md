## 晃动实机状态：未通过

已持续采集三轴诊断、校准状态、方向候选和翻页事件。用户确认竖屏；混合测试有时延迟几秒翻页、有时无反应，单独左晃与单独右晃也出现不翻页。

实际日志中，存在：

- 动作期间多次从已校准回到未校准。
- 方向候选短暂出现后撤销，`pending=0`，没有形成翻页事件。
- 成功触发后长时间停在 `armed=0`，其中一次在分析快照里已超过两分钟。
- 已识别事件送到界面的耗时与面板刷新时间见 `motion-analysis.json`，不能把它们当作物理动作到翻页的总延迟。

日志位于 `motion-serial.log`、`tilt-events.jsonl`；`monitor-state.json` 记录采集状态，`motion-analysis.json` 是带时间戳的统计快照。
这些证据确认当前回正/重新武装和重校准行为需要进一步定位；Metalio 实际安装方向的轴映射尚不能从合成回归用例直接确认。没有继续变更已安装的 beta 固件。
