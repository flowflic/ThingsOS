# Metalio 0.2.0 发布

2026-11-16 用户要求升级到 0.2.0、本地 Git commit 并发布到官网。本版包含自
`0.1.9` 后新增或改进的 Cubox 阅读同步、微读多端阅读进度同步与离线损坏章节自动修复、
横竖屏壁纸自适应与横向锁屏、GIF/图文渲染优化，以及官网使用反馈入口。
准确的官网更新说明保存在 `native/release-notes.json`，Read Pico 的发布文件与历史独立保留。

## 主要变更

- **Cubox 阅读与同步**：应用页新增 Cubox 入口，支持二维码扫码/局域网绑定账号、同步文章列表、缓存正文与图片及样式排版，管理已缓存文章并记录独立进度与时长。
- **微读多端进度同步**：退出微读书籍时上报最新阅读进度；若其他设备推进了云端位置，仅在打开对应书籍时弹窗确认是否同步跳转，取消则继续以本机位置为准，并支持离线/弱网队列与冲突保护。
- **微读离线章节修复**：离线打包或本地重建遇到损坏/未闭合章节源码时，在有限预算内复用正常章节请求重下修复并校验通过后原子替换，详见 `WEREAD-CHAPTER-REPAIR-20261115.md`。
- **壁纸横竖屏适配**：局域网上传壁纸按宽高自适应为 `684×1216`（竖图）或 `1216×684`（横图），保留完整宽度；设备端支持横屏壁纸预览与 `1216×684` 横向锁屏缓存渲染。
- **图文与动图渲染**：新增 GIF 解码与阅读器长图/图文缩放渲染支持，改进前光与阅读页面切换稳定性。
- **官网反馈入口**：官网首页新增使用反馈入口，详见 `SITE-FEEDBACK-20261115.md`。

**OTA 仅更新主程序。要将旧救援环境同步升级到 0.2.0，需要安装完整 USB 包。**
完整 USB 包会重置内部设置，SD 卡文件保留；不应为了保留设置而手工覆盖正在运行的分区。
开发者保留设置的 USB 操作仍须遵守 `METALIO-USB-FLASH-PROCEDURE.md`。

## 验证边界

此前基于 `0.1.9` 的横屏壁纸与微读提示收敛候选已完成 Metalio 实机 USB 安装（`build/landscape-wallpaper-weidu-prompt-20261116/`）：现有救援实际启动、整片 16 MiB 回读、保护区/NVS 一致性及 45 秒启动健康均通过。
本次 `0.2.0` 同时构建 Rescue 与 Main 镜像，版本描述符与 ELF 重新生成并完成主机 CTest、完整安装包/源码归档校验以及官网两端点实测核验，不在本发布步骤中再次连接设备串口刷机。
主机回归与页面校验不替代 `0.2.0` 实机 Cubox 同步、微读弱网恢复、横屏壁纸光学表现或长期待机验收。

发布证据目录：`build/publish-metalio-0.2.0/`。
