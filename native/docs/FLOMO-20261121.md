# flomo 应用（只读，2026-11-21）

参照 Cubox 的结构新增 flomo 应用：手机扫码配对 Token，浏览、搜索笔记，查看每日回顾、标签和相关笔记。
第一版只读，不调用 memo_create / memo_update / tag_rename。

## 接口（2026-11-21 用临时 Token 实测）

- 服务：`https://flomoapp.com/mcp`，MCP streamable HTTP，`serverInfo` = flomo-mcp 1.0.0。
- 鉴权：`Authorization: Bearer <token>`。Token 在 flomo 网页版 设置 → MCP / API → MCP →
  添加其他应用 → Token 连接 中创建（PRO/MAX 会员）。无 Token 返回 401 + `WWW-Authenticate`。
- `Accept` 必须同时包含 `application/json` 和 `text/event-stream`，否则 400。
- 服务端无状态：不先 `initialize`、不带 `Mcp-Session-Id` 也能直接 `tools/call`。
- 回复为 SSE（`event: message` + `data: {jsonrpc...}`），结果同时有 `structuredContent` 和
  `content[0].text`（同一 JSON）。
- 用到的工具与参数：
  - `memo_search {keywords?, tag?, end_date?, start_date?, limit≤50}`：无关键词时按创建时间倒序；
    有关键词时按相关度排序（含 `relevance`）。`end_date` 按天且包含当天。
  - `memo_batch_get {id | ids[≤10]}`：尽量全文，单次正文累计上限 30000 字。
  - `memo_recommended {id, limit?, no_same_tag?}`。
  - `tag_tree {prefix?, depth?, limit≤1000}`：`tags` 为字符串数组（层级用 `/`）。
  - `get_daily_review {}`。
- 笔记字段：`id`(12 位字母数字)、`content`(Markdown，`<mark>`/`<u>` 表示高亮/下划线，列表正文
  超过 500 字时首尾截断)、`content_truncated`、`created_at`/`updated_at`(ISO8601 +08:00)、
  `tags`、`from`、`has_image`/`has_voice`/`has_link`、`files`、`url`、`word_count`。

## 实现

- `src/flomo_protocol.c` / `include/thingsos/flomo_protocol.h`：请求体、SSE/JSON-RPC 解析、
  笔记/标签解析、正文转纯文本、分页日期、SD 列表缓存格式。主机测试 `flomo_protocol_mcp`。
- `firmware/components/thingsos_flomo`：
  - `secure.c`：Token 存 NVS（命名空间 `thingsos-flomo`，SHA-256 校验），断开时清除。
  - `flomo.c`：手机配对服务（端口 8083，8 位配对码，5 分钟有效，5 次错误锁定，校验 Host 头），
    后台任务调用 MCP（占用网络声明，与 Cubox 相同的暂停音乐让路规则），列表缓存
    `/sdcard/.thingsos/flomo/list.dat`，打开过的全文缓存 `/sdcard/.thingsos/flomo/m/<id>.txt`。
  - 分页：首页 20 条；“加载更多”用最后一条的日期作 `end_date`、每次 50 条并去重；整页重复时
    向前退一天（最多 3 次）。关键词搜索只取一页 50 条。最多保留 200 条。
- `firmware/main/flomo_ui.inc`：列表（最近 / 回顾 / 标签 / 搜索）、详情（分页阅读全文，不依赖
  SD 卡）、相关笔记、标签选择、配对、设置。
- 应用页改为 10 个图标：四行，行距由 233 改为 200，底部音频条位置不变。
