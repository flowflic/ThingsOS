01 / 微信读书，也有了墨水屏的安静

微信里的书，
来到你的墨水屏。

手机里的个人书架，现在可以带到 Read Pico。
选好想读的书，缓存下来，就能离线慢慢读。

  1. 1

    微信扫码，登录自己的账号

    连接 WiFi，进入设备「微读」，用微信扫码并确认登录。

  2. 2

    同步书架，选择想读的书

    在个人书架中选择账号可访问的书籍，按需缓存到 SD 卡。

  3. 3

    缓存完成，离线也能继续读

    已缓存书籍集中显示在书库「微读」标签，断网也能打开阅读。

通过非官方适配连接微信读书，仅缓存账号有权访问的内容。开发中的划线与同步功能会读取账号的划线/书评，并会写回阅读进度与时长（可关闭，时长首次启用需确认）。可用范围受书籍权限和服务接口影响。

时长也记在微信读书。

缓存到本地的微信读书书籍，也能记录有效阅读时长。连接 Wi-Fi 并开启上报后，可将阅读时长提交至微信读书服务端；阅读中定期提交，退出时提交余量。

安装前，
你可能想知道。

微信读书怎么用？

准备好 SD 卡并连接 WiFi，在设备「微读」中微信扫码登录，同步个人书架后选择书籍缓存。缓存完成后即可离线阅读。ThingsOS 为非官方适配，可读取内容取决于账号权限及服务接口。

手机可以直接刷机吗？

本页适配手机浏览与下载。USB 在线安装请使用电脑上的 Chrome 或 Edge；日常 WiFi 传书可在手机浏览器中操作。

第一次安装，选 USB 还是 OTA？

首次安装 ThingsOS 或从其他固件切换，请使用完整 USB 安装。OTA 文件用于已有兼容 ThingsOS 分区布局的设备，在设备的固件升级页面操作。

如何放入书籍、字体和壁纸？

将 EPUB、TXT 放入 SD 卡书籍目录，或使用设备的传书服务。额外 TTF 字体放在 SD 卡根目录的 /fonts 文件夹；JPG、PNG 壁纸放在 /wallpapers，进入电源与锁屏设置选择并预览。

电脑找不到设备怎么办？

先确认 USB 线支持数据传输，并关闭占用串口的其他程序。仍无法连接时，参照 Read Pico 官方刷机指南 ↗ 检查驱动和下载模式。
