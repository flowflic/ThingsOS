# 离线阅读时长“已上传”累计

2026-11-14，Metalio 0.1.7 开发候选。离线阅读时长页保留待上传、待确认，并新增“已上传 X 小时 XX 分 XX 秒”。移除该页底部“逻辑参考 MiuRead；签名来源 moon”文字；项目源代码、开源声明与许可证保持。

“已上传”仅统计本机离线补传通道收到明确业务成功回执的累计秒数，不包含原 Web 计时通道、失败、无回执或待确认发送。它不是微信读书账号云端全历史总时长，也不能追溯先前版本已经删除的成功记录；从本次累计功能启用后开始记账。

计数为 64 位，按账号保存在独立 NVS 记录中，格式固定并含完整 owner、最近成功批次指纹和 CRC。关闭开关、重启、重新授权和退出账号不清除累计；重新登录同账号可恢复，其他账号独立统计。前缀冲突或损坏记录不重置、不合并，显示读取失败。

批次指纹由不可变的片段 ID 与秒数组成，与目录顺序无关，重复处理最近成功回执不会再次累加。上传前先确认累计记录可读取；明确 `succ=true/1` 后先提交并回读累计，再清理源记录。保存失败保留 `.sent` 并报错，不因计数失败重新发送。成功计入后若源文件清理失败，遗留 `.sent` 仍受不重放规则保护，队列状态可能暂时与累计重叠，不能将三项相加当总阅读时长。

主机回归执行实际累计适配器，覆盖真假回执、跨批累计、顺序无关去重、账号隔离、重读恢复、超过 32 位、NVS set/commit 失败和损坏记录。页面截图和总体验证在 `build/reader-transfer-readtime-20261114/`。本轮尚未烧录或向真实账号发送时长。
