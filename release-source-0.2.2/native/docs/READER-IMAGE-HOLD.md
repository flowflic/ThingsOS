# 正文图片长按查看

2026-11-12：正文插图改为长按满 1000 ms 才进入独立图片查看模式。短按图片停留在正文，不放大、不借该次点击打开阅读菜单或翻页。封面页原有导航行为保持不变。

实现位于 `firmware/main/main.c`：

- `reader_image_hit()` 统一检测当前已绘制页面的图片区域，校验章节、正文位置和图片索引，排除菜单、图片查看、选区、脚注、密码锁定等状态。
- `reader_hold_delay()` 对正文插图使用 1000 ms；正文文字、书库和微读的既有长按时长不变。
- `reader_content_hold()` 优先分配图片长按，避免图片边缘附近文字提前进入选区。
- 连续触摸与缓冲松手分支都使用同一时长和图片入口。按住期间移动超过现有 18 px 容差会取消长按；已有 `moved` 标志保持锁定，即使移回原点也不会重新视为短按。
- 上下滑动仍进入共享翻页路径。独立图片查看打开后的缩放、拖动和返回行为保持不变；加载失败提示长按重试。

本地 EPUB、微读及其他已支持的正文插图复用同一命中与加载路径，使用旋转/竖排后的实际屏幕坐标。

`tests/reader_image_hold_ui_test.inc` 使用真实 EPUB 插图及绘制命中框，验证 0/649/999/1000 ms 边界、短按不放大、旧页面命中失效、弹层互斥、封面例外、查看返回、正常/沉浸/横屏 × 横排/竖排。既有图片拖动、文字选区和上下滑动测试继续执行。

主机与开发构建结果见 `build/image-hold-20261112/`。版本保持 0.1.7；本次未烧录、未发布，真实设备长按手感和面板效果待验收。
