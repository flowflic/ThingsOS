核心正文绘制 `src/graphics.c` 与 `main/reader_cache.inc` 与 Pico 0.3.8 一致。共享文件按 0.3.6 基线三方合并；重叠的 Metalio 修改逐项保留，并检查剩余差异。源快照、合并中间文件及比较结果在 `build/pico-038-port/`。

## Metalio 保留项

- `native/metalio/**` 与 `firmware/components/thingsos_board/**` 未改：ESP32-S31 LCD/DMA、20 MHz 供数优化、48 相 GC16/GL16、20 相 DU、故障回退、TPS65185/TCA9555、VCOM、充电安全、SD/USB、RTC、电源与休眠。
- 前光关闭/暖光/冷光/双色、10–100% 亮度、按键振动、原 NVS 键及开机/休眠恢复逻辑保留。前光页补齐左上角和左实体键返回显示页，避免新的逐级返回交互跳过一层。
- 音量键与触摸类型继续通过 Metalio 板级接口；现有键盘热区、布局切换刷新及空闲清理修复保留。键盘输入期间不按全刷周期触发整屏刷新，避免逐键闪烁。
- `thingsos_net` 未改，保留按需启动无线电、连接节流和断路保护；固件仍拒绝 Read Pico 的板型镜像。
- 麦克风、扬声器的硬件边界和已有 PA 控制未改。当前 ThingsOS Metalio 基线没有录音/播放/AI 语音应用，迁移不会新增这些功能，也不宣称音频已验收。
- Pico 0.3.8 的 S3 扫描适配层修复没有覆盖 S31 专用供数实现；相关 Pico 板级线程测试也不用于证明 S31 驱动正确。Metalio 原有 LUT 字节一致性、波形故障回退测试保留。
- Pico 官网、发布通道、版本和刷写工具未迁移。仍用 Metalio 专用打包器；所有参考检出保持只读。
