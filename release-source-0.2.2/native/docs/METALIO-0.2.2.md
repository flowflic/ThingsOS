# Metalio 0.2.2 正式版构建

2026-11-21 用户要求把项目版本升级到 0.2.2，提交当前版本并编译正式固件。官网更新说明见 `native/release-notes.json`。

## 自 0.2.1 起的主要变更

- **休眠中自动重启（看起来像自动唤醒）**
  - 根因：低功耗蓝牙控制器在 light sleep 期间仍在运行（`CONFIG_BT_CTRL_SLEEP_ENABLE` 未开启），偶尔会在关中断状态下卡住两颗核，中断看门狗随即复位（`reset=5`）。
    - 旧固件抓到的 panic 现场：核 0 卡在 `r_sym_ble_*`。
    - 新固件三次复位都是核 0 先停、核 1 约 800 ms 后停。
  - 修复：息屏和关机前停止 NimBLE 主机并禁用控制器；需要自动回连时，唤醒后重新启用并回连上次的设备。
  - 过程与证据见 `DIAGNOSTICS-20261121-sleep-trace.md`。
- **休眠诊断（保留在正式版中）**
  - 内容：RTC 保留的休眠阶段、主循环位置、每核 tick 心跳与运行任务，以及 panic 现场（`DIAG_TRACE`，kind 18）。
  - 开销：tick 钩子位于 IRAM，不调用任何函数、不取锁。
- **BLE 内存**
  - 控制器的内部 DMA 内存池（约 36 KB）每次开机只分配一次：息屏和失败时只禁用控制器，不释放内存。
  - 已保存过 BLE 设备时，即使未开自动重连，开机也会预留这部分内存。播放过音乐后连接翻页器不再提示“低功耗 DMA 不足”。
- **正文排版**
  - 横排书籍正文按 clreq 处理换行：先按正常字宽填满一行，放不下的标点再单独处理。
    - ，。、等收尾标点先挤掉字框空白，单个点号可少量借用右边距（距屏幕边缘至少 8 px）。
    - ——、…… 成组处理，可微调本行字距；仍放不下时整体换到下一行。
    - 前引号和前括号不留在行尾。
  - 软换行的行两端对齐；左右边距对称（去掉旧的 12 px 右移）。
  - 分页缓存加了版本标记，每本书首次打开时会重新分页一次。
  - 竖排正文保持固定字格，Markdown 和界面文字不受影响。
- **flomo（新应用，只读）**
  - 手机扫码配对 MCP Token，浏览、搜索笔记，查看每日回顾、标签和相关笔记，支持离线缓存。
  - 列表为卡片样式，高度随内容自适应。
  - Markdown 转义和列表空行已处理。
  - 说明见 `FLOMO-20261121.md`。
- **Cubox**：分为“最近文章”和“收藏夹”两个页签，各自保留筛选条件、列表内容和页码。收藏夹页签内可进入单个收藏夹浏览。
- **壁纸应用**：改版后包括：
  - 当前壁纸卡片与全屏预览；
  - 三种来源改为带图标和说明的行；
  - 选书改为 3 × 2 封面网格；
  - 选图改为 3 × 2 竖版缩略图，横屏图片完整显示（上下留边）并标注“横屏”；
  - 预览页底部改为两个按钮。
- **电量**：1 Hz 后台采样；开机静置 3 秒后才显示；唤醒后重新校准；改用实测放电曲线，充放电切换时重置滤波。说明见 `BATTERY-SOC-20261121.md`。
- **诊断包文件名**：改为 `ThingsOS-diagnostics-Metalio-E-Ink4-Plus-<版本>.json`，不含时间戳。

- **主程序**
