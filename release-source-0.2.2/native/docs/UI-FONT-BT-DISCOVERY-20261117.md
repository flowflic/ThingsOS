# 系统字号 50、音频搜索与 BLE 发现

用户在取消微读加载窗口前后全刷后追加两项要求：系统字号上限增加到 50；解决蓝牙漏搜。用户随后确认，既有处于配对模式的新耳机，也有 BLE 翻页器/键盘；BLE 本轮明确只需搜索显示。

## 行为

- 系统字号范围为 26–50，步长 2，NVS 接受和恢复 50；阅读字号独立。设置页缩短选项标题，大字号下时间显示有足够宽度。输入法计数、拼音和候选区按固定区域限制实际字高，按键文字继续随系统字号放大。
- 耳机/音箱搜索进行最多三轮，每轮最多等待 25 秒，结果跨轮合并；保留最多 32 个设备。主动搜索可打断旧设备重连。UART 接收缓冲由 1024 增至 4096 字节，工作任务每次最多连续读取八批 512 字节，再处理命令；不再每次仅取 128 字节。自动重连开关仍只重连已保存设备，发现新设备需要点击“搜索设备”。详细协议和验证边界见 `BLUETOOTH-AUDIO.md`。
- 蓝牙页面新增“低功耗设备”入口，独立进行 30 秒主动 BLE 扫描，显示名称、地址和信号强度；扫描响应可补充名称，完整名称不会被后续无名广播覆盖，公共/随机地址保持区分，结果满时明确提示。离开页面停止搜索。此阶段明确没有连接、配对、HID 按键或自动翻页功能，也不会把 BLE 结果提交给音频模块连接。
- 保留正常微读加载窗口前后 GL16 差分呈现、CKV 时序修复和真实扫描错误后的完整恢复。版本仍为 0.2.0，未发布、未提交。
