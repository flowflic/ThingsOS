# 壁纸应用入口与局域网上传宽度适配

用户要求：锁屏壁纸移到应用页，名称为“壁纸”；局域网壁纸优先完整显示宽度，
透明背景补白。版本保持 0.1.8，不迁移既有壁纸设置或素材。

## 应用入口

应用网格增加“壁纸”（第三行第二列），使用图片线框图标；电源与锁屏页面移除
原入口及点击热区。壁纸页标题、成功提示改为“壁纸”，返回/设置成功返回应用。
阅读统计、指定书籍封面、图片选择、预览取消、保存失败回滚保持原功能。

## 局域网图片准备

壁纸上传固定生成 684x1216 竖屏画布，与设备实际锁屏及预览比例一致。
源图全宽始终保留，等比缩放到 684 像素；缩放后较矮则上下居中补白，较长仅
居中裁上下。PNG/JPG/WebP 的透明/半透明像素与白色合成，保存为不带透明通道
的灰度 PNG 或 JPEG。按目标类别或 wallpapers 目录识别壁纸；其他图片维持
原来的按方向居中裁剪，以免改变书库封面等用途。

该变化作用于之后上传的图片，既有已裁剪文件不会恢复被裁掉的内容，需用原图
重新上传。此处没有修改设备直接读取已有 SD 图片的裁剪策略。
