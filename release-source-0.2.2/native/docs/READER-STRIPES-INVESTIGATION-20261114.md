## 可能原因排序

1. 首查屏幕扫描供数/队列或扫描中断异常。驱动用 `0x400` 同时报队列读空、归属异常、提前结束及超时；旧日志没有相位/队列证据，不能进一步锁定是哪一个。
2. 查 20 MHz 下的余量及升频重试。两个历史阅读样本都紧接 10→20 MHz 后失败，10 MHz 重画成功。这支持检查快时钟下的供数余量，不支持“频率不足所以升频”。CPU 调度、PSRAM 访问、预排版/网络/SD 等争用是待测候选，时间相邻不等于因果。
3. 若条纹持续，应查恢复是否失败/被中断，或驱动返回成功但光学状态错误。当前阅读动画出错会清屏重画；若完整成功通常不应长期保留条纹。没有本次恢复结果，不能确认这一环。
4. 内存分配失败优先级较低：历史阅读样本故障前仍有大量空闲及连续空间，没有在上述故障附近看到分配失败证据。不能据此排除本次现场内存问题；内存容量和带宽/时限不同。
