# BLE 连接、配对与键盘 / 翻页器输入

用户在已有低功耗设备搜索显示功能上，明确追加“支持 BLE 设备连接”。本轮实现位于独立 `native/firmware/components/thingsos_ble/`，版本保持 0.2.0。

后续按用户要求将 BLE 与音频设备合并到设置 → 蓝牙的同一设备列表和搜索按钮；不再需要进入单独低功耗子列表。入口及验证记录见 [BLUETOOTH-UNIFIED-UI-20261117.md](BLUETOOTH-UNIFIED-UI-20261117.md)。

## 已实现的路径

单个 BLE 中央连接独立于外置 BH1098G 音频链路，两个设备记录命名空间分开。用户从附近/已保存列表进入详情，再确认连接；支持断开、忘记、重新连接和可关闭的自动重连。最多保留四个设备，地址类型及公共/随机身份地址一起保存。应用记录有版本、容量、终止符和 CRC 校验；NimBLE 配对密钥由 SDK 的 NVS 后端保存。只有连接完成后保存设备，写入失败会明确提示；忘记会同时移除配对密钥和本机记录。

使用安装的 ESP-IDF v6.1 NimBLE 中央/GATT 客户端 API。连接、加密、服务发现、读取报告描述符及订阅通知全部异步，带连接代次和操作超时；过期回调不能修改新连接。保存设备后的意外断线最多尝试三次重连；主动断开会停止当前重连。空闲时不维持 10 Hz 服务轮询，只有命令/连接过程/待重连任务才启动服务计时器。

配对使用动态六位验证码或用户确认的数字比较；键盘需要输入验证码时，阅读器显示提示。没有固定通用配对码或自动接受数字比较。旧配对不一致时，用户可忘记后重新配对。输入通知必须来自当前已加密连接，且完成输入报告订阅后才启用。连接成功但没有可用的标准输入服务时会明确显示，不声称该设备可以操作阅读器。

标准 HID-over-GATT 支持至多四个 HID 服务、十六个输入报告，报告描述符限 2048 字节。独立解析器处理键盘数组/位图、修饰键、Caps Lock、Report ID、消费控制数组/位图；重复按住报告不重复产生翻页。方向/翻页/媒体及音量按键映射到既有主任务导航；键盘可在输入框编辑字母、数字和标点，使用现有拼音候选，支持光标、删除、确认/取消。笔记编辑回车换行，Ctrl+回车保存，Ctrl+空格切换中英文。锁屏/PIN/休眠时丢弃远端输入，断开后清除旧按键队列。普通输入字符和配对码不写入应用串口日志。

蓝牙主机缓存、状态表及 HID 描述符工作区优先放入 PSRAM；控制器/PHY 首次初始化和 NVS 读写使用既有 I/O 互斥锁，避免与面板扫描、应用写入交叠。显示驱动、CKV 校验和真实扫描错误恢复保持原实现。

## 验证边界和来源

使用本机 SDK 的 `host/ble_gap.h`、`host/ble_gatt.h`、`host/ble_sm.h`、`host/ble_store.h` 和 NimBLE NPL API；实现未复制或修改 SDK HID 主机代码。标准 HID 常量同时核对项目已固定的 TinyUSB `src/class/hid/hid.h`（MIT），没有修改该参考文件。新状态机、报告解析、界面和应用输入分派均独立编写。

主机测试直接运行实际 BLE 服务的 GAP/GATT 回调，模拟动态/确认验证码、完整加密/报告/CCC 就绪、陈旧回调、操作超时、重连上限、断开清队列、存储失败和密钥移除；解析测试覆盖数组、位图、Report ID、按住去重、截断/畸形输入及有界模糊数据。UI 测试覆盖详情、配对、验证码、保存/忘记和键盘文字/拼音及锁屏边界。

构建、测试、候选及首轮安装证据在 `build/ble-hid-20261117/`。70/70 回归通过，另有默认 ATT MTU 23、22 字节分段读取报告描述符的专项服务测试通过。预览为主机测试画布，不是真实外设验收照片。

首次 `usb-install/` 基线采集完成 45 秒，看到已安装 ELF 和启动健康，但缺少 UI ready 行，门禁因此在任何 Flash 写入前停止。保留该失败记录后，仅重试了一次基线；`usb-install-attempt2/` 完整捕获 UI/ELF/健康并完成备份、救援启动、回读、保护区和选择器验证，安装了 ELF `e176c1152...` 的连接主体。启动日志确认 BLE 服务处于空闲、没有已保存 BLE 外设；这不能证明真实无线配对和按键已验证。

随后补齐键盘 Enter/Escape 在紧凑日期/重命名编辑器中的确认/取消路由，70/70 回归再次通过。最新候选及安装记录改在 `build/ble-hid-input-routing-20261117-r2/`，主应用 7,599,680 字节，BIN SHA-256 `52866c1fd5e7aa76c787e8c7569acaa211c33bd4df5a8535fa7d640c6dbc547f`，ELF `a6ea0cb238481c33f78aa66b61c809cc179ee49c7b54582846089093c126a6f0`；版本仍为 0.2.0，安装状态以该目录 `usb-install/result.json` 为准。

主机测试和启动健康不能替代真实外设的配对、断线重连、输入和射频/耗电验收；专有 GATT 协议、BLE 音频、鼠标指针/手势、非标准翻页器协议不在标准键盘输入路径中。

最新输入路由候选已完成安装：完整 16 MiB 备份和回读、实际救援启动、主程序/保护区/选择器及 45 秒启动健康均通过，用户 NVS 与本次备份一致。实际启动 ELF 为 `a6ea0cb23...`，书库界面就绪、CKV 689/无故障，串口已关闭。启动时 BLE 已保存设备数为 0，未出现配对或 HID 输入事件，因此没有将健康启动记为真实外设验收。
