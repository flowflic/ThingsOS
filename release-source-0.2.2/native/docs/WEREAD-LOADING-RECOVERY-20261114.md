# 微读加载帧失败恢复

针对用户照片中的横向条纹增加防护；照片尚不能确认根因。

- 加载卡片/转圈提交（`keyboard==5`）返回任意扫描错误时，使用现有时钟恢复状态机切到 10 MHz。
- 从当前完整画布重新打包目标，包括背景及卡片，保留灰阶；随后全屏物理清屏并从白底执行 GC16 重绘。
- 包括已处于 `panel_recovery_pending` 的加载提交，每次提交最多立即恢复一次。恢复失败继续保留待恢复标志，沿用已有时钟退避，不在函数内循环。
- 打包失败不扫描；成功恢复仍沿用已有成功帧及电源关闭检查。缓存任务、章节数据、动画频率、常规阅读路径、版本均不调整。

主机故障注入：`panel_clock_recovery_test.c` 覆盖整屏目标替换（含局部区域之外）、重绘失败只执行一次、失败后不升频、打包失败跳过扫描。测试通过。

此防护依赖驱动返回错误；未报错的光学残留无法由本路径识别。没有烧录、发布或本次异常的实机复现验收。

主应用 `native/build.ps1` 构建及 JPEG 应用符号检查通过，产物为 `build/native-idf/ThingsOS_native.bin`，日志 `build/loading-recovery-build.log`。初次受限环境构建遇到工具加载 WinError 623，改在获准的环境中完成构建。
