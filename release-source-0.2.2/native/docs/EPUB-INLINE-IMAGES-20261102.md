# 《诡秘之主》插图失败与阅读静置麻点（2026-11-02）

目标是 Metalio E-Ink4-Plus 墨水屏固件。电脑上的同一份 EPUB 只用作复现输入，
不修改原书：`D:\localsend\诡秘之主（精校全本）.epub`，36,604,629 B，
SHA-256 `4039d5b297155c25acfc3ca1c11881f77ef932365867767538910116006f932b`。

## 插图：实机确认的两个原因

1. RGBA PNG 解码需要大块连续 PSRAM。实机 `logo00.png` 是 1080×700，
   stb 解码时申请 3,024,000 B；最大连续块只有 1,736,692 B，即使总空闲约 7 MiB 也失败。
   这触发了「图片暂时无法显示，正文可继续阅读」，并非电脑版阅读问题。
2. 指定的「诡秘星球世界地图」对应 `OEBPS/Text/part3-6.xhtml` →
   `OEBPS/Images/a2.jpg`，3800×7400、约 2812 万像素，压缩文件 1,369,323 B。
   原通用解码器限制单边 4096 和 2 Mi 像素，设备日志确认探测失败。
   此书共有 114 张图（102 JPEG、12 PNG），其中 29 张超过原像素限制。

## 固件修正

- 阅读 PNG 使用独立行解码：两行过滤缓冲、zlib 流和灰度输出，避免整张 RGBA/解压数据。
  校验 PNG CRC、块边界、顺序和完整 zlib 流；保留透明通道对白底的合成。
  支持非交错灰度/索引色 1/2/4/8 bit、RGB/灰度透明/RGBA 8 bit。
  其他已有格式保留通用解码路径；未宣称大幅交错或 16 bit PNG 已优化。
- 阅读 JPEG 使用本项目已有、与 ESP32-S31 ROM 符号隔离的 TJpgDec，
  在 MCU 块解码时缩小，必要时直接采样到有上限的输出，避免整幅原尺寸分配。
  世界地图按竖屏输出 624×1216，灰度缓冲 758,784 B，解码工作区 16 KiB。
- 输出不超过 1 Mi 像素；PNG 源限制 32 Mi 像素、JPEG 源限制 64 Mi 像素，单边 16384，
  压缩成员仍保持 2 MiB 限制，不无限放开内存边界。
- 图片加载同时检查 PSRAM 总量与最大连续块，必要时释放可重建的阅读预缓存。
- 壁纸和普通封面的旧有接口与限制保留；修复通用解码失败日志里的未初始化尺寸变量。

## 麻点：回归线索与候选

用户反馈阅读页停留一会后麻点逐渐明显，手机难以拍出。被动日志及源码确认当前固件
每次成功刷新后保电 3 秒。2026-10-25 同页约 3 分钟测试通过的版本采用立即断轨，
后续 3 秒保电优化重新引入了这一差异，见 `READER-STATIC-SPECKLE.md`。
这是一条可定位的生命周期回归，尚不是麻点单一根因的光学证明。

本候选仅把阅读更新恢复为立即断轨并执行现有数字输出读回；普通界面的 3 秒窗口保留。
失败、休眠同样立即断轨。没有改变波形、时序、VCOM 电压/EEPROM、充电策略或前光设置。
同型号官方、kiikoread S31、dpReader31 的最新源码也在最终阅读输出后断轨，
官方允许翻页动画内部中间帧续电。源码对比见 `REFRESH-COMPARISON.md` 后续记录。

## 用户复测发现的问题与第二次修正

用户反馈有图页面明显变慢，并提供「组织与势力概况表」黑底白字照片。
该表对应 `part3-9.xhtml` 的 a5/a6/a7.jpg。第一候选虽然通过全图解码成功测试，
但没有覆盖这组实际图的白色像素正确性，因此不能把 114/114 解码成功当作正确显示验收。

黑底在主机纯像素中与照片一致：a5 原图缩小后的白色区域约 67.9%，错误输出只有 6.8%。
原因是 TJpgDec 的 `JD_FORMAT=2/JD_FASTDECODE=1` 灰度路径中，
有符号快速 IDCT 结果可大于 255 或小于 0，直接转 uint8 会绕回；白色 256 变为黑色 0。
第二候选在本项目 MCU 输出适配器内对受影响块先饱和截断、再平均缩放；
固定的 vendor 解码器与许可证未改动。a5/a6/a7 修正后白色比例分别约 71.9%/70.4%/67.4%，
像素图已核对为白底黑字。比例与参考缩放稍有差异，不宣称逐像素相同。

新增 quality=50 的纯白 JPEG 用例，其快速 IDCT 白块恰为 256；
固定旧程序输出全 0，新程序所有输出均 ≥250。证据 `white-before-a5.pgm`、
`white-test-v2.log`、`table-pixel-check.json` 和 `table-after-comparison.png`。

第一候选对所有 JPEG 使用块解码，普通小图也承担了较慢路径；第二候选恢复
1 Mi 像素以内普通 JPEG 的原通用解码路径，失败才退回有界缩小解码。
另外增加两槽解码像素缓存，总上限 2 MiB；点图、绘制正文和状态栏重绘可复用，
返回独立副本保留原释放约定，关闭书籍时清空，横竖屏分别校验尺寸。
