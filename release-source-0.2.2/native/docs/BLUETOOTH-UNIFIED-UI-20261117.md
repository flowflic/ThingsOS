# 蓝牙统一设备入口

用户要求将低功耗设备与音频设备统一到一个入口。设置 → 蓝牙现在只有一份设备列表，搜索同时提交 BH1098G 耳机/音箱查询及 ESP32 NimBLE 扫描；列表按设备注明音频/低功耗，不再跳转独立的“低功耗设备”子列表。附近设备和已保存设备分别合并显示、每页五条，详情统一提供连接、断开、忘记和对应设备类型的自动重连设置。

音频搜索及已保存设备连接可以从本地模式按需启动 BH1098G；启动确认成功后保存开启状态。音频查询期间可直接选择已发现耳机连接，不必等待三轮查询结束。停止搜索只停止正在搜索的传输，不断开另一传输上已经建立的连接。退出蓝牙页面后停止扫描；连接保持，用户可在设备详情主动断开。关闭音频模块的操作放在音频设备详情中。

两种协议的任务、配对状态和持久化数据仍独立；不会把同 MAC 的经典蓝牙设备与带类型的 BLE 地址误合并，也不将 BLE 广播当作音频能力。BLE 验证码配对、加密和 HID 输入的能力与边界见 [BLE-CONNECTIONS-HID-20261117.md](BLE-CONNECTIONS-HID-20261117.md)。原有显示条纹修复、加载差分刷新和字号上限 50 保留；版本仍为 0.2.0。

现有 UI 回归覆盖同屏混合结果、相同 MAC 的两种传输、混合列表分页/保存/忘记、音频关闭后直接重连、双链路保持及验证码流程。实际服务回归检查关闭状态下搜索/连接请求、扫描中切换连接。候选、编译/回归日志及后续安装证据位于 `build/bt-unified-20261117/`。主机回归与启动验证不等同真实耳机、键盘、翻页器的射频配对和操作验收。
