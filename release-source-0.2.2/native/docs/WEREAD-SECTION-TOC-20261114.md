# 微读分部内目录修复（2026-11-14）

## 原书根因与复现

原书《未竟的依恋：理解和疗愈内在的创伤》，ID 3300013223。用户授权 USB
诊断后只读复制原书缓存：服务端目录共 10 条，把第 1–16 章合并在三个分部
正文里，具体章标题使用 h2，非目录小标题带 sigil_not_in_toc。
初次取证时只缓存前三个前置文件；用户完成整本缓存后，仍在主机复现目录仅 10 项。

实际根因：三个分部的 4/8/4 个 h2 标题能精确匹配当前正文，但脚注生成的 [n]
标记使 thingsos_wd_map 的全章 UTF-16 云端坐标校验失败。旧目录构建把云端
映射成功当作本地目录的必要条件，因而丢弃全部 16 个本地章节。

## 修复

本地目录保留“当前章节正文中整行、唯一、按序匹配”的严格锚点条件，去掉对
云端来源映射成功的依赖。仅生成现有阅读正文的本地字节偏移，不修改正文、
书签或云端坐标。云端映射本身保持失败关闭，不将本地偏移冒充来源位置。

同时补齐在线已缓存章节的目录补全；新正文下载后使内存目录失效并重建，
在线目录不复用 ZIP 身份的离线缓存。支持正文内 h1（至少缩进一级），仍排除
sigil_not_in_toc 和不唯一标题。离线导航缓存版本升至 3，旧索引自动重建。
尚未缓存的分部保留根目录，不因进入目录而强制下载全书。
