# ThingsOS Metalio 0.1.2（2026-10-31）

按用户要求，将项目及默认主/救援固件统一升级到 **0.1.2**，包含当前
Metalio 工作区的全部应用更新。`native/VERSION` 为共同版本源；历史
0.1.1 发布包、安装记录及其验收边界保留。

## 相比正式版 0.1.1

| 项目 | 更新 |
| --- | --- |
| 大书架 | 上限 4096 → 20000 本，响应 2 → 24 MiB；书架分页扫描增加 16 KiB 缓冲 |
| 同步与登录 | 书架套接字超时 15 → 60 秒，写 SD 响应的读取总预算 60 → 300 秒；首次登录标识请求最多尝试三次；扫码成功但同步失败时给出专用提示 |
| 缓存预取 | 两个任务提前获取章节上下文，按序消费结果；资源不足时回退串行；原有断点续传保留 |
| 并发稳定性 | 每个预取任务独立连接、共享 Cookie 互斥保护、仅由 I/O 锁持有者释放和重取、等待预取时让出 I/O 锁、任务结束调用 `vTaskDelete(NULL)` |
| 章节目录 | 三次请求均使用 25 秒超时；从目录提示切换到章节标题时用正常灰阶刷新清理旧状态行 |
| 蓝牙音频 | 播放连续三次写入失败时上报链路丢失、暂停播放，蓝牙任务清除连接并恢复本机输出路由 |
| ima 与音乐 | 音乐播放期间允许验证凭证及读取知识库列表；上传、结果检查保留独占网络声明 |
| WiFi 唤醒重连 | 息屏时暂停重试和旧连接计时，唤醒后重置失败次数并异步重连已保存网络；手动关闭 WiFi、手动断开及未保存网络时不强行连接 |

正式版已有的键盘修复、单次/日期范围闹钟、断点续传、连接复用、录音、
音乐、ima 基础上传流程及板级行为继续保留，不重复计为本轮新增。

WiFi 唤醒修正：板级息屏会直接停止无线驱动，旧逻辑唤醒仅重新启动驱动，
网络层保留的失败次数和绝对连接期限可能已耗尽或过期。因此加入明确的网络
休眠/唤醒通知，休眠期间不消耗断线重试；唤醒后开启新的有限连接窗口，
不等待 DHCP 完成才恢复界面。若息屏或关机失败返回界面，同样恢复网络策略。
新增回归覆盖重复唤醒、过期连接窗口、手动关网/断开、无保存网络及驱动失败。

## 构建与交付

```powershell
./native/build.ps1 -Rescue
./native/build.ps1
python ./native/package_metalio.py
```

输出为 `build/native-usb/ThingsOS-metalio-0.1.2-usb.bin`、
`ThingsOS-metalio-0.1.2-ota.bin` 和 `metalio-manifest-0.1.2.json`。
USB 完整包用于完整安装，打包时 NVS 区域为擦除态；OTA 包只有主应用。
本次构建不连接设备、不刷机、不提交 Git；0.1.2 已按用户要求发布到官网，见下节。

构建、主机回归、镜像描述符和包完整性的核对结果记录在
`build/version-0.1.2-verification.json`，构建日志存放于 `build/`。

本次主机回归 **43/43 通过**（含新增 WiFi 唤醒重连及实际 UI 休眠/唤醒调用
回归）；主/救援固件构建、主应用 JPEG 链接检查、两应用版本描述符、USB
各分区内容及哈希、擦除态 NVS 和主应用启动选择数据均通过核对。
主固件 ELF 同时确认预取、蓝牙链路丢失处理和 WiFi 休眠/唤醒符号已链接。
