## 使用

- 最多 4 个闹钟，可新增、编辑、开关和删除。返回键取消未保存的编辑。
- 设置 24 小时制的小时、分钟；每天、工作日（周一至周五）、周末，也可逐个选择星期。至少选择一天。
- 从与音乐应用相同的 `/sdcard/music` 文件列表选择现有 WAV/MP3，不复制音频。沿用音乐列表的 64 项上限。
- 独立响铃音量 10–100%，默认 60%；结束后恢复设备原音量。
- 到时唤醒息屏并显示提醒，循环所选音乐。可点击停止或稍后 5 分钟；3 分钟自动停止。电源短按或左侧返回键停止，右侧下一键稍后提醒。
- 日期、时间和时区沿用系统设置；无有效日期时不触发，页面提示先校时。工作日不查询法定节假日或调休。

## 调度、持久化和资源边界

配置与已触发日期以版本化 NVS blob `thingsos-ui/alarms-v1` 保存。加载时检查精确长度、版本、各字段范围、字符串终止、文件扩展名及路径边界。保存失败保留原配置。触发日期是递增记录，防止同一天的循环轮询、重启及向后校时重复响铃；用户编辑并保存视为新计划，已过去的时间从下一个符合日期开始。

正常主循环检测精确分钟；被任务占用时最多补触发过去 5 分钟内的一次计划。首次启动只检查当前分钟，不补播更早的闹钟。定时依赖现有 Metalio 轻睡眠约 2 秒周期唤醒，不设置 RTC 硬件闹钟、不改变 BSP、唤醒源、VCOM、面板波形或充电策略。设备彻底关机、救援模式及 USB 直连期间不能响铃；OTA/传输也可能延迟或错过超出窗口的计划。

所有调度、唤醒、绘制和输入在主 UI 任务。响铃界面拦截触摸、按键和 AI 录音，暂停后台阅读预绘及倾斜输入；支持竖屏及横屏阅读中的提醒。音频仍由现有音频任务解码，并走当前音乐输出路由（含已连接蓝牙），不自动切换扬声器。

正在录音、录音准备或保存时，保留原音频任务，显示等待说明；录音结束后在本次 3 分钟提醒窗口内重试。未取得音频所有权的提醒停止时不会停止原录音。音乐播放可由铃声替换，停止后不自动恢复原曲。SD 缺失、文件被删除或音频失败时显示原因，并每 3 秒重试。多个同时到期的计划排队，各待播计划最多保留 5 分钟；长时间占用会使后续计划过期。稍后提醒仅保存在本次开机内存，重启后不恢复。

触发记录写入失败时本次仍提醒，并显示“重启可能重复提醒”的错误说明；不把失败写入当作持久化成功。
