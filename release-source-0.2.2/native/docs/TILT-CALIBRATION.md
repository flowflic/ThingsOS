## 问题与修复

Metalio 曾在初始校准时额外要求部分握姿的绝对横滚角不超过低/中/高档
19/15/12度。超过门槛就逐样本清零稳定计时，使正常的倾斜握姿无法校准，
也无法开始翻页；调高灵敏度反而缩小可校准范围。

`native/src/tilt.c` 现恢复 Pico 的相对校准语义：有效且稳定的握姿持续
400ms 后成为零点。保留重力幅值过滤、稳定性判断、方向确认、冷却、回正、
触摸屏蔽及单个意图的时效规则。

正常校准后，转腕回到原握姿不应反向翻页。若启用时已侧倾并保持400ms，
该姿态也会成为零点；随后回到物理水平可能构成相对零点的一次转腕。
仅靠稳定加速度样本无法辨别这两类相同的初始姿态，这与 Pico 的行为一致。
